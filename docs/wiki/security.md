# Безопасность

## Shopify

- Приложение имеет только `read_products`.
- Генератор не содержит операций изменения товаров или магазина.
- Секреты находятся вне Git и имеют ограниченные права доступа.
- Полученный токен не сохраняется на диск и не выводится в журнал.
- Подписанный URL Bulk-файла не журналируется и не получает Admin-токен в заголовке.

## Сервер

- Сервис работает от отдельного пользователя `pricefeed`.
- systemd включает `NoNewPrivileges`, `PrivateTmp`, `ProtectSystem=strict` и ограниченные `ReadWritePaths`.
- Закрытое состояние хранится отдельно от каталога Nginx.
- Публикуется только точный путь XML, а не каталог кода или временных файлов.
- Методы кроме `GET` и `HEAD` запрещены.
- Доступ ограничен IP КИП и loopback-адресами.

## Что не должно попадать в Git

- `.env`;
- `config.local.json`;
- `runtime/` и реальные JSONL/XML каталога;
- реальные client secret или Admin token;
- временные и lock-файлы.

## Ротация

При подозрении на утечку client secret нужно создать новый секрет в Shopify, заменить защищённый серверный файл, проверить получение токена новым секретом и только затем отозвать старый. После изменения перезапустить сервис вручную и проверить журнал.
