# Wiki генератора price-feed

Эта wiki описывает собственный генератор товарного XML/YML-фида Shopify для прайсмониторинга в КИП. Проект получает каталог только на чтение, создаёт отдельный `offer` для каждого варианта, проверяет результат и публикует последнюю корректную версию файла.

## Как и когда обновляется фид

После установки и включения `price-feed.timer` на сервере фид формируется **каждый час**. Первый автоматический запуск происходит через пять минут после запуска сервера. Расписание задано в `deploy/price-feed.timer`:

```ini
OnBootSec=5min
OnUnitActiveSec=1h
```

Включение расписания:

```sh
sudo systemctl enable --now price-feed.timer
systemctl list-timers price-feed.timer
```

Пока проект не установлен на сервер и таймер не включён, автоматических запусков нет.

## Как запустить вручную

На установленном сервере запустить генерацию и сразу посмотреть результат:

```sh
sudo systemctl start price-feed.service
sudo journalctl -u price-feed.service -n 50 --no-pager
```

Успешный журнал содержит `"event": "success"`. Итоговый файл находится в `/var/www/price-feed/feed.xml` и отдаётся по адресу `https://ВАШ-ДОМЕН/feeds/price-feed.xml`.

Подробности: [эксплуатация и диагностика](operations.md) и [установка на сервер](deployment.md).

## Границы готовности

Локальное подключение к Routes&Roads и полный Shopify Bulk-экспорт проверены. Генератор не изменяет товары, остатки, тему или настройки магазина. Серверная установка и постоянный HTTPS-адрес ещё не выполнены. Валидный XML и сходство с образцом не подтверждают совместимость с КИП: нужна тестовая загрузка со стороны КИП.
