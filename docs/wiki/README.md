# Wiki генератора price-feed

Эта wiki описывает собственный генератор товарного XML/YML-фида Shopify для прайсмониторинга в КИП. Проект получает каталог только на чтение, создаёт отдельный `offer` для каждого варианта, проверяет результат и публикует последнюю корректную версию файла.

## Границы готовности

Локальное подключение к Routes&Roads и полный Shopify Bulk-экспорт проверены. Генератор не изменяет товары, остатки, тему или настройки магазина. Серверная установка и постоянный HTTPS-адрес ещё не выполнены. Валидный XML и сходство с образцом не подтверждают совместимость с КИП: нужна тестовая загрузка со стороны КИП.
