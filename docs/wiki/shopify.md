# Подключение Shopify

## Текущая интеграция

- Магазин: `ra4abi-aj.myshopify.com`.
- Основной домен: `https://www.routesandroads.fr`.
- Приложение: `price-feed` в Shopify Dev Dashboard.
- Разрешение: только `read_products`.
- Версия Admin API генератора: `2026-04`.
- Товары, остатки, тема и настройки магазина генератором не изменяются.

## Авторизация

Предпочтительный вариант для приложения и магазина в одной организации:

```env
SHOPIFY_CLIENT_ID=...
SHOPIFY_CLIENT_SECRET=...
```

При каждом запуске генератор получает краткоживущий токен через client credentials и хранит его только в памяти. Альтернативно можно задать `SHOPIFY_ADMIN_TOKEN` с действующим offline token; он имеет приоритет.

Секреты нельзя хранить в Git, JSON-конфиге, аргументах команды или журналах. На сервере используется `/etc/price-feed/credentials.env` с правами `600`.

## Bulk Operations

Запрос выбирает варианты по `catalog_query`, сейчас `product_status:active`. Для каждого варианта читаются ID, название, SKU, barcode, цена, суммарный остаток, признак отслеживания, картинка и опции; у товара читаются ID, название, handle, статус, productType, vendor, URL и главная картинка.

`bulkOperationRunQuery` является GraphQL mutation только потому, что запускает серверную задачу. Сама операция читает каталог и не меняет Shopify.

## Если потребуются отдельные склады

Текущая логика использует суммарный `inventoryQuantity`. Она не доказывает физическое наличие на конкретном собственном складе. Для отбора по locations или `on_hand` потребуется отдельное согласование правила, изменение запроса и, возможно, дополнительные read-only scopes `read_inventory` и `read_locations`.
