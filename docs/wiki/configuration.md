# Конфигурация

Базовый пример находится в `config.example.json`. Реальную конфигурацию следует хранить отдельно от Git, на сервере — `/etc/price-feed/config.json`.

## Подтверждённый локальный профиль Routes&Roads

| Настройка | Значение |
|---|---|
| Рынок | France |
| Страна | FR |
| Валюта | EUR |
| Язык | основной, `fr` |
| Цена | базовая Shopify, `price_mode=base` |
| Каталог | активные товары, `product_status:active` |
| Наличие | суммарный отслеживаемый остаток больше нуля |
| Ошибки отдельных вариантов | `missing_policy=skip` |

## Важные параметры

- `live_confirmed`: защита от случайного запуска незаполненного live-конфига.
- `availability_confirmed`: подтверждение выбранного правила наличия.
- `currency`: значение для `currencyId` и проверок цены.
- `categories`, `category_map`: явная карта `productType → category ID`.
- `option_params`: только подтверждённые соответствия названий опций параметрам образца.
- `extra_data`: подтверждённые uuid и параметры из внешней учётной системы либо пустая строка.
- `output`: путь итогового XML.
- `state_dir`: закрытый каталог для lock, состояния Bulk и временной обработки.
- `retries`, таймауты и лимиты: границы повторов, ожидания и размера скачивания.
- `min_offers`, `max_skip_fraction`, `max_drop_fraction`: дополнительные защитные пороги.

## Категории

Скрипт `scripts/build-local-config.py` строит локальную карту из реальных непустых `productType`. Технический числовой ID детерминированно вычисляется из точного названия, поэтому повторный запуск сохраняет его. Пустой тип не заменяется вымышленной категорией.

Новый `productType`, отсутствующий в серверной карте, будет пропущен до обновления конфигурации. Изменение дерева категорий следует согласовать с КИП.
