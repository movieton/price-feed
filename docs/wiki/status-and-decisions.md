# Текущее состояние и принятые решения

## Реализовано

- Python-генератор без БД, Docker и внешних сервисов.
- Shopify Admin GraphQL с минимальным доступом `read_products`.
- Bulk Operations для полного каталога.
- Отдельный `offer` на каждый вариант Shopify.
- Базовые цены EUR и обязательный `currencyId=EUR`.
- Пропуск только проблемного варианта вместо остановки всего обмена.
- Проверка XML, цен, валюты, обязательных полей и уникальности ID.
- Атомарная публикация с сохранением последней корректной версии.
- Повторы, таймауты, throttling, блокировка параллельных запусков и JSON-журнал.
- systemd timer раз в час.
- Nginx-шаблон с HTTPS-путём и allowlist IP КИП.
- Набор из 25 автоматических тестов.

## Принятые решения

- Выгружаются активные товары.
- Используется основной французский язык.
- Используются базовые цены магазина в EUR.
- Наличие определяется по суммарному отслеживаемому остатку.
- Обязательное поле отсутствует — вариант пропускается, обмен продолжается.
- Интервал после установки на сервер — один час.
- Фид может работать на отдельном сервере.
- Доступ к XML разрешён IP `5.129.221.173` и локальным адресам сервера.

## Осталось выполнить

1. Получить доступ к выбранному Linux-серверу и его DNS.
2. Установить репозиторий, конфигурацию и секреты.
3. Настроить поддомен, TLS, systemd и Nginx.
4. Выполнить первый серверный Bulk-запуск и проверить журнал.
5. Проверить HTTP 200 со стороны КИП и 403 с постороннего IP.
6. Выполнить тестовую загрузку КИП и получить подтверждение формата, включая `currencyId`.
7. Подтвердить, что суммарный Shopify inventory соответствует нужному правилу наличия.

## Не считается подтверждённым

- Совместимость с КИП до тестового импорта.
- Рабочий публичный URL до серверного развёртывания.
- Наличие на конкретных складах.
- Рыночные цены Shopify Markets: сейчас используются базовые цены.
